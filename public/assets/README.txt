Theme assets (optional)
======================

Theme images are loaded from the public folder:

  public/images/                    - All theme images (logos, sliders, products)
    logo-white.png, logo-black.png  - Header & footer logos
    logo-placeholder.svg            - Fallback if logos missing
    demoes/demo22/
      slider/                       - Home slider images
      products/                     - Product images
      payment-icon.png              - Footer payment icons

CSS and JS from the Porto theme are already in the app (globals.css).
Font Awesome is loaded from CDN in the layout.
